Git - Работа с Local Repository 

Первым делом создаём папку, в которой будем хранить все наши репозитории, изменения и прочее - база данных git (локальный репозиторий) и далее выполняем команду:

n0rf1x@n0rf1x-HP-nix:~/myproj0$ git init .
Инициализирован пустой репозиторий Git в /home/n0rf1x/myproj0/.git/

Для дополнительной проверки можно выполнить команду, которая проверит, создалась ли скрытая папка внутри репозитория:

ls -la

n0rf1x@n0rf1x-HP-nix:~/myproj0$ ls -la
drwxrwxr-x  3 n0rf1x n0rf1x 4096 окт 20 22:15 .
drwxr-x--- 18 n0rf1x n0rf1x 4096 окт 20 22:14 ..
drwxrwxr-x  7 n0rf1x n0rf1x 4096 окт 20 22:15 .git	/папка создалась - всё корректно

Команда, которая является одной из наиболее часто используемых:

git status 

Статусов бывает несколько

1) on branch master - nothing to commit - отсутствие коммитов - нахождение в режиме ожидания релиза
2) untracked files: - появились новые файлы, которые git смог обнаружить внутри своего репозитория, но он еще не записал их (перед выполнением команды git status мы создали файл через команду: echo "First file project" > file1.txt)
3) changing - changes to be committed - добавление файлов в статус changing - то есть файлы изменены и готовы для коммита (снимка)
4) nothing to commit - отсутствие коммитов в связи с тем, что снимок был выполнен на основе тех файлов, которые были добавлены ранее 


Для добавления файлов в репозиторий используется команда: 

git add * 		/* - звездочка это добавление всех файлов; дополнительно можно через точку - git add . ; также можно добавлять и по одному файлу

Для выполнения снимка (коммита) используется команда: 

git commit -m "My first commit to Local Repository" 		/флаг -m (message) обязателен

При условии, если вы каким-либо образом изменяете файлы, которые ранее были добавлены в репозиторий - создается новая версия этих файлов, которую необходимо добавлять в новом коммите, например:

nano file1.txt

+Special editing for test new version this file in new commit. 
Thanks blablacar. A CHE

После этого, команда git status покажет, что файл file1.txt был изменен и предложит его добавить в релиз и выполнить последующий коммит

Выполняем по очереди команды git add * и git commit -m "Update file1 and added new file3" - результат:
